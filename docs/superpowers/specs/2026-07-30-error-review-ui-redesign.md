# 错题复习板块 UI 重设计

> 状态：已确认  
> 日期：2026-07-30  
> 风格：极简精英风（蓝白色系）

## 背景

当前错题复习板块在三处位置（侧边栏卡片、复习顶栏、能力面板入口）全部使用灰白中性色，与面试对话区没有视觉区分，代码注释写的是"紫色主题"但实际无色彩运用。用户反馈：奇怪、不搭、不美观。

## 设计目标

1. 用蓝色系建立复习板块的专属视觉身份，与 app 主色（indigo #4f46e5）协调
2. 极简克制 — 白底为主，蓝色只做点睛，不喧宾夺主
3. 提升质感 — 精细间距、圆角、光晕、等宽数字等细节

## 配色体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 主强调色 | `#3b82f6` | 图标、按钮、左边框、数字 |
| 深蓝 hover | `#2563eb` | 按钮悬停、激活加深 |
| 极浅蓝底 | `#eff6ff` | 偶尔使用，不常用 |
| 淡蓝边框 | `#bfdbfe` | 激活态边框 |
| 激活底色 | `#f8faff` | 卡片激活时极微弱的蓝底 |
| 主文字 | `#0f172a` | 标题、正文 |
| 副文字 | `#64748b` / `#94a3b8` | 辅助信息、标签 |
| 卡片底 | `#fff` | 默认背景 |
| 侧边栏底 | `#f9fafb` | 侧边栏背景（保持现有） |

### 设计原则

- **白底留白** — 大面积白色，蓝色只在关键信号处出现
- **左边框 = 身份标识** — 3px 蓝色左边框是唯一结构色，替换传统彩色背景
- **光晕代替背景色** — 激活态用 box-shadow 光晕，不靠大面积换色
- **等宽数字** — tabular-nums + SF Mono 字体，数字对齐不跳动

## 组件设计

### 1. 侧边栏错题卡片

位置：`ChatView.vue` 侧边栏，面试对话列表上方

```
┌──────────────────────────┐
│ ▎ 📋  错题复习       12  │  ← 白底 + 3px 蓝色左边框
│ ▎     3方向·12道错题     │  ← 图标无色(SVG)继承蓝色
└──────────────────────────┘
```

**规格：**
- 背景 `#fff`，边框 `1px solid #e2e8f0`，左边框 `3px solid #3b82f6`
- 圆角 `10px`，内边距 `14px`，元素间距 `12px`
- 图标 34px 圆角方块，颜色 `#3b82f6`（无背景色块）
- 标题 `13px / 600`，副文 `10px / #94a3b8`
- 数字徽章：`13px / 700 / #3b82f6`，等宽数字，无背景色块
- hover：左边框变 `#2563eb`，轻微阴影 `0 2px 8px rgba(0,0,0,0.06)`
- 激活态：背景 `#f8faff`，边框 `#bfdbfe`，外光晕 `0 0 0 3px rgba(59,130,246,0.08)`
- 完成态（全部清除）：左边框变灰 `#e2e8f0`，整体 `opacity: 0.5`

### 2. 复习顶栏

位置：`ChatView.vue` 主聊天区顶部，仅在复习模式显示

```
┌──────────────────────────────────────────────────┐
│ 错题复习 · Java并发   ●●●●◉○○○○○○○○   4 / 12   │
└──────────────────────────────────────────────────┘
```

**规格：**
- 背景 `#fff`，底边框 `1px solid #f1f5f9`
- 内边距 `16px 28px`
- 标题 `14px / 600`，方向名 `11px / #64748b`
- **分段步进圆点**（替代传统进度条）：
  - 12 个小圆点，每个 `7px`，间距 `3px`
  - 默认 `#e2e8f0`，完成 `#3b82f6`，当前 `#2563eb` + `scale(1.3)` + 发光环 `0 0 0 3px rgba(37,99,235,0.2)`
- 计数器：分子 `15px / 700 / #3b82f6` 等宽，分母 `12px / #94a3b8`
- 过渡动画 `0.3s ease`

### 3. 能力面板入口卡片

位置：`AbilityPanel.vue`，在统计卡片和雷达图之后

```
┌──────────────────────────────────┐
│  (📋)  错题复习           [→]   │
│        3个方向·12道错题待复习     │
└──────────────────────────────────┘
```

**规格：**
- 背景 `#fff`，边框 `1px solid #f1f5f9`，圆角 `14px`，内边距 `20px`
- 图标：`42px` 圆形，`#f8fafc` 底色 + `#3b82f6` 图标色
- 标题 `14px / 600`，描述 `11px / #94a3b8`
- **圆形箭头按钮**：`38px` 圆形，`#3b82f6` 底色 + 白色箭头
  - 阴影 `0 2px 10px rgba(59,130,246,0.25)`
  - hover：背景变 `#2563eb`，阴影加深，`scale(1.05)`
- 无错题态：整体 `opacity: 0.4`，按钮变灰 `#cbd5e1`
