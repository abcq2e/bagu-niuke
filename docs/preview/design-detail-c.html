🎯 极简精英风 · 设计原则总结

  • 少即是多 — 白底大面积留白，蓝色只在关键信号处出现
  • 左边框 = 身份标识 — 3px 蓝色左边框是唯一的结构色，替换了传统的彩色背景
  • 圆点 > 进度条 — 分段步进比连续进度条更有"题目感"
  • 圆形按钮 = 行动召唤 — 蓝色实心圆箭头是整个界面最重的色彩元素，引导点击
  • 等宽数字 = 数据感 — 用 tabular-nums 让数字对齐不跳动
  • 光晕代替背景色 — 激活态用 box-shadow 光晕，不靠大面积换色
